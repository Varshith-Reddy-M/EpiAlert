# Output files

- `epialert_results.csv`: one row per region/week with measurements and detector outputs.
- `alert_events.csv`: only observations where CUSUM or EWMA signaled.
- `current_alerts.csv`: alerts in the latest available CDC week.
- `overall_summary.csv`: project-level evaluation summary.
- `yearly_summary.csv`: yearly observations and alert counts/rates.
- `region_summary.csv`: region-level alert summary.
- `latest_week_activity.csv`: latest-week activity, sorted by ILITOTAL.
- `validation_checks.csv`: automated integrity checks.
